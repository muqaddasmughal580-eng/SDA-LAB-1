SDA Lab 01 – Hotel Reservation System

This lab focuses on identifying the main classes, objects, and methods of a Hotel Reservation System.

Main Classes

- Guest — makeReservation(), cancelReservation(), viewReservation(), updateInformation()
- Room — checkAvailability(), reserveRoom(), updateStatus(), calculatePrice()
- Reservation — createReservation(), cancelReservation(), modifyReservation(), confirmReservation()
- Hotel
- Payment
- Receptionist
- Invoice
- Hotel Service
- Check-in

Objective

The purpose of this lab is to understand how real-world entities can be represented as classes and how their functions/methods define their responsibilities in a software system.
